Odds check

One tap pulls current prices from TAB, Sportsbet, Betfair, PointsBet, Ladbrokes and Neds, then checks every head to head, line and total against the board's win chances. Nothing updates on its own, so you only use credits when you tap.

What to check

Settings
Copy your Odds API keys and GitHub token (any text containing them, even the setup link), then tap this. The home-screen app keeps its own storage, separate from Safari, so set the keys up here inside the app.

How it works: for each selection the page takes the best price across the six bookmakers (Betfair after your commission) and works out the model's expected return at that price, using the same win chances, line and total maths as the board. "Take at" is the lowest price worth betting at your minimum edge. Stakes use the Kelly settings you saved on the board.

Lines and totals: bookmakers often hang different lines, so each side shows the line and price with the best expected return, and the other books' lines under it.

Games that have already started are skipped, because the board's numbers are pre-game. Odds come from The Odds API and can be a minute or two behind the bookmakers' own sites, so check the price before you bet.
